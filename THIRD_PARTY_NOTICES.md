# Third-party components

Little Days uses the following open-source components. Their respective licenses continue to apply. This notice does not assign an open-source license to the project's own source code.

| Component | Purpose | License / source |
| --- | --- | --- |
| Capacitor core, Android, iOS and official plugins | Native runtime, camera, filesystem, sharing, app events, haptics | MIT — https://github.com/ionic-team/capacitor and https://github.com/ionic-team/capacitor-plugins |
| esbuild | Bundle the native adapter | MIT — https://github.com/evanw/esbuild |
| fflate | Create portable ZIP artifacts | MIT — https://github.com/101arrowz/fflate |
| AndroidX and Android build tooling | Android shell and build | Apache-2.0 and component-specific terms — https://developer.android.com/jetpack/androidx |
| Gradle Wrapper | Reproducible Android builds | Apache-2.0 — https://gradle.org/ |

Exact JavaScript dependency versions are recorded in `pnpm-lock.yaml`. Dependency license files remain in their installed distributions; use the relevant package manager and native build tools to retrieve them. The application icon and sample SVG illustrations were created for this project. It does not download remote photos or bundle font files; Times New Roman and Chinese sans-serif fonts resolve from the user's operating system.
