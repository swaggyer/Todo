# 网页部署与 PWA

## 公开访问

[打开 day todo 网页版](https://little-days-todo-m7q2.shouuu336.chatgpt.site/#today)。当前站点已开放公开访问，无需 Codex 或 ChatGPT 账号。

公开访问沿用原网址，因此不需要迁移同一浏览器中的现有记录。每位访问者的记录保存在自己的浏览器中，互不共享；关闭、更新和备份的具体规则见[数据保存说明](DATA.md)。

## 本地预览

```sh
pnpm install --frozen-lockfile
pnpm dev
```

以终端显示的网址为准。请通过本地服务器打开网页；直接双击 HTML 文件会使用 `file://` 来源，不能完整验证数据库、离线缓存与安装能力。

## 构建与托管

```sh
pnpm check
pnpm build
```

把 `apps/web/dist` 内的所有文件部署到静态托管服务。通用配置：

| 项目 | 值 |
| --- | --- |
| 安装命令 | `pnpm install --frozen-lockfile` |
| 构建命令 | `pnpm build` |
| 输出目录 | `apps/web/dist` |
| Node.js | `24` |
| 环境变量 | 默认不需要 |

构建目录使用相对资源路径，可放在网站根目录或子目录。界面通过 `#today`、`#lists`、`#notes` 切换，无需为这三个页面配置服务端路由重写。

正式站点使用 HTTPS。将 `index.html`、应用清单和 Service Worker 配置为可重新验证，避免托管服务长期缓存旧入口。所有生成资源必须完整上传，勿只替换 HTML。

## 安装到手机主屏幕

- Android：用支持安装的浏览器打开网站，在浏览器菜单中选择安装或添加到主屏幕。

首次完整访问后，应用资源可通过离线缓存继续使用。使用相机、导入文件及主屏幕安装时，实际入口和系统提示由设备与浏览器决定。

## 更新与数据

每次更新部署完整的新构建。重新打开或刷新后，应用会按缓存策略获取更新；本地待办与照片不属于网页构建产物，不应在发布时清除。

首次离线打开尚未访问过的网站无法下载所需资源。清除站点数据会同时删除该来源的本地记录与离线资源，操作前请[导出备份](DATA.md)。

从原来的 Sites 域名迁移到新域名时，先在旧站导出 JSON，再在新站导入；浏览器不会把两个域名的数据库自动搬过去。
