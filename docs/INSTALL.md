# 手机安装与下载

更新日期：2026-10-29。

## Android 测试版

[下载 Android 测试版 APK](https://github.com/swaggyer/Todo/releases/download/android-preview-1.0.0/little-days-android-preview.apk)

1. 用安卓手机浏览器打开上面的链接，直接下载 APK；无需登录 GitHub 或解压 ZIP。
2. 下载完成后，从下载通知或文件管理器中打开 `little-days-android-preview.apk`。
3. 按系统提示允许当前浏览器或文件管理器安装此应用，再确认安装。系统菜单名称随手机品牌而异。

要求 Android 7.0 及以上。手机仍需确认安装，下载链接不能自动或静默安装应用。APK 约 8.3 MB，作为公开 Release 附件保存，不受 Actions 产物 14 天保留期限制；仓库或该附件被删除后，链接将失效。

这是调试签名的测试版，已通过原生编译，尚未完成真机验证，未上架应用商店。每次构建的调试签名可能不同，不能保证后续版本覆盖升级。**更换版本或卸载前，先在应用内导出备份**；卸载可能清除本机记录。

## 记录与备份

网页与 Android 各自保存在本机，没有跨设备自动同步。换设备、切换浏览器、改用 App 或卸载前，先导出 JSON 备份，再在目标设备导入。见[数据备份与迁移](DATA.md)。
