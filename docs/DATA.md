# 数据备份与迁移

## 保存位置

待办、完成状态、随记和照片默认保存在当前设备的 IndexedDB 数据库 `little-days-v1` 中。day todo 改名后保留此数据库名称及应用标识 `com.swaggyer.littledays`，避免改变已有数据的存储身份。应用不要求登录，不会自动上传这些内容。

## 关闭网页与版本更新

在普通浏览模式下，点击“保存”并完成本机写入后，正常刷新、关闭网页后重新打开，以及同一网址的网站更新，都不会主动清空记录。网站的静态资源缓存与个人记录分开保存；更新资源不会删除数据库。

请继续使用同一设备、同一浏览器及相同网址。网站已开放公开访问，不需要 Codex 或 ChatGPT 账号；公开页面不会把你的本机待办或照片分享给其他访问者。

Today 只显示当前日期范围内有效的事项。跨天后，昨天的单日事项可能不再出现在 Today，但仍保留在 Lists，并非被删除。

浏览器本地保存不等同于云备份。无痕模式结束、清除站点数据、浏览器存储回收、换设备或换浏览器，都可能让本机记录不可用。重要记录应定期导出 JSON 备份；当前没有跨设备自动同步。参见[浏览器存储与清理规则](https://developer.mozilla.org/en-US/docs/Web/API/Storage_API/Storage_quotas_and_eviction_criteria)。

以下位置各有独立数据：

- 原 Sites 域名与新部署域名。
- 不同浏览器或不同浏览器配置文件。
- Android 原生应用与普通浏览器。
- iPhone 原生应用与 Safari / 主屏幕 Web App。
- 不同手机、电脑与系统用户。

安装手机 App 不会自动导入原网页中的记录。

## 从网页迁移到手机

1. 在旧网页中打开“数据备份”。
2. 选择“导出备份”，保存生成的 JSON 文件；其中包含随记照片。
3. 将文件传到目标设备。
4. 打开新网页或手机 App，进入“数据备份 → 导入备份”。
5. 选择文件，确认 Today、Lists 和随记中的记录与照片。

更换域名、换设备或在网页与原生 App 之间迁移，都采用相同步骤。

## 导入规则

导入会校验备份格式并按记录 ID 合并：

- 新 ID 的待办与随记加入本地。
- 本地已有相同 ID 时保留当前本地记录。
- 不会清空已有内容，也不会把两个版本逐字段同步。

因此，备份导入适合迁移与补充记录，不是冲突解决或自动云同步功能。当前单个导入文件上限为 80 MB。

## 日常备份

定期把完整备份保存在自己管理的位置。照片会增加备份文件和设备存储占用。清除浏览器数据、卸载手机 App、更换手机或恢复系统前，先导出并确认备份能打开。

源码包与 GitHub 仓库不包含运行时的个人待办、随记或照片。不要把个人备份放进公开源码仓库。
